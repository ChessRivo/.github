
# ChessRivo ♟️

### Play • Learn • Improve

**ChessRivo** is an independent online chess platform for players around the world.

Play real-time chess, improve with interactive lessons and puzzles, join tournaments, compete in global rankings and analyze your completed games with Stockfish.

## ChessRivo features

- ♟️ Real-time online chess
- 🎯 Rating-based matchmaking
- 🤖 Play against AI
- 🎓 Interactive chess lessons
- 🧩 Chess puzzles
- 🏆 Online tournaments
- 🌍 Global player rankings
- 📊 Stockfish-powered post-game analysis
- 👤 Public player profiles
- 🧠 Personal Coach recommendations
